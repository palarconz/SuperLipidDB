# SuperLipidDB

A Python project for modeling, standardizing, and querying a curated lipid database using a unified metadata structure.

This project brings together lipid species metadata from multiple public reference sources, including LipidBlast, LIPID MAPS, SwissLipids, and HMDB. The goal is to create a clean, searchable database of lipid identifiers and their associated properties such as shorthand notation, common and systematic names, formulae, exact mass, cross references, and synonyms.

## Why this project

The main value of this repository is the infrastructure around the lipid dataset:

- normalization of shorthand lipid names
- unified metadata model for lipid species
- alias and synonym support
- cross-reference IDs across sources
- SQLite-based storage and querying
- JSON/CSV export for downstream analysis
- reusable lookup logic for biochemical metadata

This makes it useful as a practical data engineering project centered on reference data management for lipid annotations.

## Project structure

- `gestor_lipidos.py` — core database manager, normalization utilities, query logic and metadata handling
- `poblar_base_datos.py` — curated lipid catalog used to populate the database
- `SuperLipidDB_PA.json` — exported database records in JSON format
- `SuperLipidDB_PA.sqlite` — SQLite database generated by the project

## Features

- standardized lipid abbreviations such as `PC(34:1)`
- common and systematic names
- chemical metadata: formula, exact mass, SMILES, InChI Key
- database identifiers: LipidMaps, SwissLipids, HMDB, CHEBI, PubChem
- synonym registry and alias search
- exact and partial lookup support
- support for adduct mass calculations for common ion forms

## Quick start

### 1) Populate the database

```bash
python poblar_base_datos.py
```

This creates or updates the SQLite database and exports the current dataset to the JSON file.

### 2) Query lipid records

```bash
python -c "from gestor_lipidos import buscar_lipido; print(buscar_lipido('PC(34:1)'))"
```

### 3) Use the database layer

```bash
python -c "from gestor_lipidos import buscar_lipido; print(buscar_lipido('PC(34:1)'))"
```

The repository is primarily a metadata and query system for lipid records, not a statistical reporting tool.

## Example usage

```python
from gestor_lipidos import buscar_lipido

resultados = buscar_lipido('PC 34:1')
for row in resultados:
    print(row['abreviatura'], row['nombre_comun'], row['masa_exacta'])
```

## Data model

Each lipid entry includes fields such as:

- `abreviatura`
- `abreviatura_lipidblast`
- `abreviatura_cadenas`
- `nombre_comun`
- `nombre_sistematico`
- `categoria`
- `clase`
- `subclase`
- `formula`
- `masa_exacta`
- `lipidmaps_id`
- `swisslipids_id`
- `hmdb_id`
- `chebi_id`
- `pubchem_cid`
- `smiles`
- `inchi_key`
- `fuentes`
